# Bug Report: BUG-0001

## Summary
**Title**: Civic Doctrines and Active Slots Not Saved or Loaded in SaveRepository
**ID**: BUG-0001
**Severity**: S2-Major
**Priority**: P1-Immediate
**Status**: Fixed
**Reported**: 2026-08-25
**Reporter**: AI Static QA Auditor

## Classification
- **Category**: Game State / Persistence
- **System**: Civic Doctrines & Kurultay Meclisi (`SaveRepository`, `GameStateNotifier`)
- **Frequency**: Always (100% upon reload)
- **Regression**: Yes (Civic doctrines system Phase 1 introduced recently)

## Environment
- **Build**: commit `d806e7c` (main)
- **Platform**: Flutter Web, Android, iOS
- **Scene/Level**: Core World & Kurultay Modal
- **Game State**: Any state with unlocked or equipped civic doctrines

## Reproduction Steps
**Preconditions**: Player has at least 1 Crown (Şan) and Castle Level 2.

1. Open the Töre & Kurultay Meclisi dialog (`ToreDialog`).
2. Unlock a locked doctrine card (e.g., *Göçer İaşesi* or *Yurt Düzeni*) by spending Crowns.
3. Equip the doctrine into an active doctrine slot.
4. Close and refresh the browser / restart the game application.
5. Open the Töre & Kurultay Meclisi dialog again.

**Expected Result**: Previously unlocked doctrines remain unlocked (`isUnlocked: true`) and active doctrine slots retain their equipped card IDs.
**Actual Result**: Unlocked doctrines revert to default initial state (`isUnlocked: false`) and active slots revert to default initial cards.

## Technical Context
- **Likely affected files**:
  - `lib/data/save_repository.dart`
  - `lib/presentation/providers/game_state_notifier.dart`
- **Related systems**: Economy multipliers relying on `getActiveDoctrines()`.
- **Possible root cause**: `SaveDataBundle` and `SaveRepository.saveGame` do not include `doctrines` or `activeDoctrineSlots` in the JSON serialization bundle.

## Recommended Fix
1. Add `doctrines` (as `List<DoctrineCardModel>`) and `activeDoctrineSlots` (as `Map<DoctrineSlotType, String?>`) to `SaveDataBundle`.
2. Serialize both in `SaveRepository.saveGame` and deserialize in `SaveRepository.loadGame`.
3. Update `GameStateNotifier.initialize()` to assign loaded doctrines and slots into state.
