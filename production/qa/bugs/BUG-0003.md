# Bug Report: BUG-0003

## Summary
**Title**: unlockDoctrine and equipDoctrine Missing Immediate Save Invocations
**ID**: BUG-0003
**Severity**: S3-Minor
**Priority**: P2-Next Sprint
**Status**: Fixed
**Reported**: 2026-08-25
**Reporter**: AI Static QA Auditor

## Classification
- **Category**: Game State / Persistence
- **System**: Civic Doctrines & Kurultay Meclisi (`GameStateNotifier`)
- **Frequency**: Often (if user closes app before 10s autosave)
- **Regression**: No

## Environment
- **Build**: commit `d806e7c` (main)
- **Platform**: Flutter Web, Android, iOS
- **Scene/Level**: Töre & Kurultay Meclisi Modal

## Reproduction Steps
**Preconditions**: Player has Crowns.

1. Open Kurultay Meclisi.
2. Unlock a doctrine or equip/unequip doctrine slots.
3. Immediately close or refresh the game window within 1-2 seconds.

**Expected Result**: Changes are immediately saved to disk (`saveGame()`).
**Actual Result**: State is only saved if the 10-second timer happens to tick before closure.

## Technical Context
- **Likely affected files**:
  - `lib/presentation/providers/game_state_notifier.dart:1370-1415`
- **Possible root cause**: `unlockDoctrine` and `equipDoctrine` mutate `state` and play audio, but do not call `saveGame()`.

## Recommended Fix
Add `saveGame();` at the end of both `unlockDoctrine` and `equipDoctrine`.
