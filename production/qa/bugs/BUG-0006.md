## Reproduction Steps
**Preconditions**: Player owns an altıgen tile and builds a structure (e.g., Farm or Worker Camp).

1. Select the developed tile.
2. Observe available actions in `TileActionSheet`.
3. Try to change the building type or demolish it to build a different structure (e.g. replacing a farm with a windmill for synergy).

**Expected Result**: Player has an option to demolish or replace the building (with a confirmation modal or partial resource refund).
**Actual Result**: There is no demolish action available in the UI; once built, the tile is permanently bound to that building type for the rest of the run.

## Technical Context
- **Likely affected files**:
  - `lib/presentation/widgets/tile_action_sheet.dart`
  - `lib/presentation/providers/game_state_notifier.dart`

## Recommended Fix
Add a `demolishBuilding(HexAxial coord)` method to `GameStateNotifier` and a tactile "YIK / KALDIR" button in `_buildBuildingDetailSection` with a confirmation dialog.
