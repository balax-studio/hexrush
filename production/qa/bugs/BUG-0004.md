# Bug Report: BUG-0004

## Summary
**Title**: Prestige Migration (resetGame) Resets totalMigrations Counter to Zero
**ID**: BUG-0004
**Severity**: S3-Minor
**Priority**: P2-Next Sprint
**Status**: Fixed
**Reported**: 2026-08-25
**Reporter**: AI Static QA Auditor

## Classification
- **Category**: Game State / Progression
- **System**: Prestige / Migration System (`GameStateNotifier.resetGame`)
- **Frequency**: Always (upon completing a migration)
- **Regression**: No

## Environment
- **Build**: commit `d806e7c` (main)
- **Platform**: All
- **Scene/Level**: Settings Dialog / Prestige Migration

## Reproduction Steps
**Preconditions**: Player has conquered multiple tiles and triggers a reset/migration.

1. Open Settings -> Great Migration (Büyük Göç / Reset).
2. Confirm migration.
3. Check `progression.totalMigrations`.

**Expected Result**: `progression.totalMigrations` increases by 1 to track player migration count across runs.
**Actual Result**: `progression.totalMigrations` is reset to 0 because `state = _createInitialState()` replaces progression with default initial values without preserving the incremented migration count.

## Technical Context
- **Likely affected files**:
  - `lib/presentation/providers/game_state_notifier.dart:1416-1438`
- **Possible root cause**: `resetGame` calls `_createInitialState()`, which sets `totalMigrations: 0`.

## Recommended Fix
In `GameStateNotifier.resetGame`:
```dart
final int nextMigrations = state.progression.totalMigrations + 1;
state = _createInitialState();
state = state.copyWith(
  resources: state.resources.copyWith(tamgas: totalTamgas),
  progression: state.progression.copyWith(totalMigrations: nextMigrations),
  ...
);
```
