# Bug Report: BUG-0007

## Summary
**Title**: HexGridPainter Uses Prohibited Raw System Emojis for Biomes and Buildings
**ID**: BUG-0007
**Severity**: S3-Minor
**Priority**: P1-Immediate
**Status**: Fixed
**Resolution**: Replaced all raw Unicode emojis in `_drawBiomeIcon` and `_drawBuilding` with `LowPolyBuildingRenderer.renderBiomeDecoration` and `LowPolyBuildingRenderer.renderBuilding`.
**Reported**: 2026-08-25
**Reporter**: AI Static QA Auditor

## Classification
- **Category**: UI / Visual Design & Anti-Slop Compliance
- **System**: Canvas Rendering (`HexGridPainter`)
- **Frequency**: Always (when Canvas fallback painter is active)
- **Regression**: Yes (Legacy Canvas fallback)

## Environment
- **Build**: commit `d806e7c` (main)
- **Platform**: Flutter Web, Android, iOS
- **Scene/Level**: 2D Canvas Map Fallback

## Reproduction Steps
1. Inspect `lib/presentation/canvas/hex_grid_painter.dart` lines 124-203.
2. Observe `_drawBiomeIcon` and `_drawBuilding` implementations.
3. Note usage of `🌾`, `🌲`, `🏔️`, `🌊`, `🏰`, `🍞`, `⛏️` system emojis rendered directly via `_drawText(canvas, emoji, ...)`.

**Expected Result**: Canvas rendering should use geometric vector paths, `Icons.*`, or low-poly shapes in compliance with the Zero-Emoji mandate in `AGENTS.md`.
**Actual Result**: System emojis are drawn on the canvas, causing platform-dependent visual slop and inconsistent emoji rendering on Android/iOS/Web.

## Technical Context
- **Likely affected files**:
  - `lib/presentation/canvas/hex_grid_painter.dart:124-203`
- **Related systems**: `LowPolyBuildingRenderer`, `GameVectorIcons`.
- **Possible root cause**: Legacy placeholder emoji code was not converted to geometric paths when voxel/low-poly systems were introduced.

## Recommended Fix
Replace `_drawBiomeIcon` and `_drawBuilding` text emoji drawing with `LowPolyBuildingRenderer.renderBiomeDecoration` and `LowPolyBuildingRenderer.renderBuilding` or custom vector path drawing.
