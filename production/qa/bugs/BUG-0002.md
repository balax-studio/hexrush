# Bug Report: BUG-0002

## Summary
**Title**: Hardcoded 5.0 Wood Check and Static Button Text in TileActionSheet Winter Heating UI
**ID**: BUG-0002
**Severity**: S3-Minor
**Priority**: P1-Immediate
**Status**: Fixed
**Reported**: 2026-08-25
**Reporter**: AI Static QA Auditor

## Classification
- **Category**: UI / Economy Logic
- **System**: Tile Action Sheet (`TileActionSheet`) & Winter Season Mechanics
- **Frequency**: Always (during Winter with Kış Otağı doctrine)
- **Regression**: Unknown

## Environment
- **Build**: commit `d806e7c` (main)
- **Platform**: Flutter Web, Android, iOS
- **Scene/Level**: In-game Hex Map & Bottom Action Sheet
- **Game State**: Season is Winter, `doc_kis_otagi` doctrine is active, Player Wood is between 2.0 and 4.9.

## Reproduction Steps
**Preconditions**: Season is Winter. The *Kış Otağı* doctrine is active (reducing heating wood cost to 2.0). Player has 3.0 Wood.

1. Select an owned, unheated tile with a production building during Winter.
2. Observe the bottom `TileActionSheet` action buttons.
3. Observe the "ISIT (5 ODUN)" button status.

**Expected Result**: Button should display `ISIT (2 ODUN)` and be enabled since player has 3.0 Wood (>= 2.0 Wood required).
**Actual Result**: Button displays `ISIT (5 ODUN)` and is disabled (`canWarm == false`) because line 412 hardcodes `wood >= 5.0`.

## Technical Context
- **Likely affected files**:
  - `lib/presentation/widgets/tile_action_sheet.dart:412, 549`
- **Related systems**: `EconomyCalculator.getWinterWarmWoodCost`, `GameStateNotifier.warmTile`.
- **Possible root cause**: Line 412 calculates `canWarm` using hardcoded `5.0` instead of calling `EconomyCalculator.getWinterWarmWoodCost(notifier.getActiveDoctrines())`. Line 549 hardcodes text `'ISIT (5 ODUN)'`.

## Recommended Fix
1. Calculate `final double woodCost = EconomyCalculator.getWinterWarmWoodCost(notifier.getActiveDoctrines());` in `_buildBuildingDetailSection`.
2. Check `final bool canWarm = isWinter && !tile.isWarmed && gameState.resources.wood >= woodCost;`.
3. Update button label to `'ISIT (${woodCost.toInt()} ODUN)'`.
