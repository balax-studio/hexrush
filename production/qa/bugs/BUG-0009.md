- **Category**: UI / Responsive Layout

## Environment
- **Build**: commit `d806e7c` (main)
- **Platform**: Small screen mobile devices / compact web previews

## Reproduction Steps
1. Open game on a viewport with width 320px.
2. Select a tile with 3 active synergies (e.g. Farm next to Desert, Wetland, and Windmill).
3. Observe synergy chips in `TileActionSheet`.

**Expected Result**: Long synergy tags gracefully wrap with comfortable padding and no text overflow artifacts.
**Actual Result**: Synergy tags can squeeze against sheet borders or clip without `TextOverflow.ellipsis`.

## Technical Context
- **Likely affected files**:
  - `lib/presentation/widgets/tile_action_sheet.dart:450-472`

## Recommended Fix
Add `maxLines: 1, overflow: TextOverflow.ellipsis` to the synergy label Text widget in `TileActionSheet`.
